# Draper Norwood website

A Next.js App Router site for Draper Norwood. The current redesign is on `redesign/beneath-the-surface`. The original site is recoverable at `checkpoint/pre-redesign-2026-09-07` (e3b5345); the earlier editorial concept is preserved at `checkpoint/before-beneath-surface-2026-09-07` (9632c14).

## Run

- `npm ci`
- `npm run dev` — local development
- `npm run build` — production build
- `npm run start` — production server
- `npm run typecheck` and `npm run lint`
- `node --test tests/*.test.cjs` — isolated inquiry and public website reader tests; email, DNS, and HTTP providers are mocked, so tests send no email and fetch no remote sites

## Structure

- `src/app/page.tsx`: homepage
- `src/components/SurfaceExperience.tsx`: challenge selection, adaptive perspective, public website read, work ordering, and inquiry handoff
- `src/components/BusinessCutaway.tsx`: original-logo architectural model with pointer and keyboard-accessible depth control
- `src/components/WorkingModel.tsx`: four authored interactive demonstrations
- `src/lib/perspectives.ts`: copy, case ordering, accent colors, and transparent keyword routing
- `src/app/api/first-read/route.ts` and `src/lib/public-site-read.ts`: bounded public HTML reader
- `src/app/work/[slug]/page.tsx`: four statically generated case studies
- `src/lib/work.ts`: case copy, metrics, and evidence boundaries
- `src/components/CTASection.tsx`: always-visible inquiry form
- `src/app/actions/sendEmail.ts`: validated server action, Resend notification and confirmation
- `src/app/surface.css`: responsive visual system and reduced-motion behavior
- `src/app/fonts`: self-hosted fonts and OFL licenses
- `docs/BENEATH-THE-SURFACE.md`: current creative decisions, implementation, and release boundaries
- `docs/RELEASE-NOTES.md`: historical first-concept notes and the retained case evidence/asset ledger

## How the experience works

The original Draper Norwood identity anchors a layered model of a business: what the world sees, the intelligence underneath, and the work that makes it real. A visitor selects a challenge or describes it in their own words. Four authored perspectives change the explanation, working demonstration, accent, and order of real case studies. Free text uses local keyword matching; these perspectives are not generated by an LLM.

The optional website reader fetches one public HTML page and extracts observable titles, headings, navigation, and contact signals. It returns a clearly bounded working hypothesis, a downloadable text brief, and an explicit inquiry-prefill action. It does not inspect internal systems, render JavaScript, measure analytics, or claim a complete business audit. No AI service credentials are required.

The reader permits public HTTP(S) addresses, rejects credentials and nonstandard ports, validates and pins DNS addresses on every hop, and rejects private/reserved networks. It caps redirects, response size, request size, and elapsed time. Its bounded in-memory rate limit is per server instance. Remote sites may block automated requests or depend on JavaScript; failures are shown without pretending a read succeeded.

## Email and analytics

Set `RESEND_API_KEY` in the hosting environment to enable delivery. The sender remains `hello@drapernorwood.com`; its domain must be verified in the existing Resend account. No secrets are stored in this repository. Without a key, the form reports that sending is unavailable and the direct email link remains available.

The Vercel Analytics integration is retained. Its collection depends on the existing Vercel project's configuration. The in-memory rate limiter is bounded but per instance; it is not a distributed abuse control.

## Publication

The redesign is prepared separately from the live site. A local build and mocked tests do not prove live email deliverability. Verify the existing host environment and perform a separately authorized real delivery check before replacing production.

Canonical URLs use `https://www.drapernorwood.com`, matching the existing public site's redirect. Homepage anchors `#home`, `#work`, `#about`, `#services`, and `#contact` remain available; `#explore` opens the challenge selector. All case routes have their own metadata and appear in the sitemap.
